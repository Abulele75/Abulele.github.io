# SPRINT BACKLOG 
**Duration:** 5 months  
**Roadmap:** Seven Sprints

## Sprint 1 — Testing Foundations
**Sprint Goal:** Understand the foundations of software development and testing.

- Set up access to the required systems and tools.
- Learn the basics of the Software Development Life Cycle (SDLC).
- Learn the basics of the Software Testing Life Cycle (STLC).
- Understand Agile principles.
- Practise simple Linux terminal tasks.

## Sprint 2 — Source Control and Python Habits
**Sprint Goal:** Develop source control and Python programming skills.

- Learn Git and GitFlow.
- Practise Python fundamentals.
- Set up and manage Python environments.
- Apply consistent version-control practices.

## Sprint 3 — First Automation Layer
**Sprint Goal:** Create a basic automated UI test using BDD principles.

- Understand Behaviour-Driven Development (BDD).
- Write Behave-style test scenarios.
- Set up the automation project structure.
- Create a simple Selenium UI test.

## Sprints 4–5 — Framework-Based UI Automation
**Sprint Goal:** Develop a maintainable UI automation project.

- Integrate Toolium with Behave.
- Identify and use stable element locators.
- Structure the UI testing project for maintainability.
- Develop the framework-based UI automation solution.

## Sprint 6 — Performance Testing Basics
**Sprint Goal:** Set up and demonstrate a basic performance test.

- Set up Apache JMeter.
- Create basic samplers and listeners.
- Understand key performance metrics.
- Execute and demonstrate a simple performance test.

## Sprint 7 — API Testing Flow
**Sprint Goal:** Build and demonstrate an end-to-end API testing flow.

- Create Postman collections.
- Test common API methods.
- Validate API responses.
- Demonstrate an end-to-end API testing flow.

## Sprint Completion
At the end of each sprint, progress is reviewed against the sprint goal. Completed work, outstanding tasks and challenges are documented, and the next sprint's activities are planned according to the programme roadmap.

## Reflection
Creating the sprint backlog was an exciting experience because the sprints introduced me to tools and concepts that I had not learned at university. Being exposed to technologies such as Python, Selenium, Behave, Toolium, JMeter and Postman gave me the opportunity to explore real-world QA automation practices. I was excited to gain practical skills beyond my academic knowledge and understand how these tools are used in the workplace. This experience has helped me build confidence, improve my technical abilities and prepare myself for the expectations of the IT industry. Overall, the sprints have been valuable learning opportunities that are helping me become a more skilled, adaptable and employable graduate.
