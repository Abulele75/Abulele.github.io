|US02| Sprint 1	  | As an intern, I want to use Linux commands so that I can perform basic tasks using the terminal.                                          |
|US03| Sprint 2	  | As an intern, I want to use Git and GitFlow so that I can manage code changes and collaborate effectively.                                |
|US04| Sprint 2   |	As an intern, I want to learn Python fundamentals and manage Python environments so that I can write and maintain test scripts.           |

## Tasks

Sprint 1 — Testing foundations
[ ] Set up required accounts and tool access.
[ ] Study the Software Development Life Cycle (SDLC).
[ ] Understand the Software Testing Life Cycle (STLC).
[ ] Learn Agile principles and terminology.
[ ] Practise basic Linux terminal commands.

Sprint 2 — Git and Python
[ ] Practise Git commands and version control.
[ ] Learn the GitFlow branching workflow.
[ ] Practise Python variables, data types, conditions and loops.
[ ] Write basic Python functions and scripts.
[ ] Create and manage Python environments.

Sprint 3 — First automation layer
[ ] Understand Behaviour-Driven Development (BDD).
[ ] Write feature files and scenarios using Gherkin syntax.
[ ] Set up a basic Behave automation project.
[ ] Create a simple Selenium UI test.
[ ] Run the test and review its results.

Sprints 4–5 — Framework-based UI automation
[ ] Set up a Toolium project integrated with Behave.
[ ] Create and execute framework-based UI tests.
[ ] Identify stable element locators.
[ ] Organise test code for maintainability.
[ ] Run tests and troubleshoot failures.

Sprint 6 — Performance testing
[ ] Set up Apache JMeter.
[ ] Create a basic test plan and samplers.
[ ] Add listeners to view test results.
[ ] Learn key performance metrics.
[ ] Run and review a simple performance test.

Sprint 7 — API testing
[ ] Create a Postman collection.
[ ] Test common HTTP methods such as GET, POST, PUT and DELETE.
[ ] Validate response status codes and response data.
[ ] Organise and execute API requests.
[ ] Demonstrate an end-to-end API testing flow.

## Reflection
Creating the user stories and tasks helped me break down my internship learning goals into clear, achievable activities. I enjoyed seeing how each task connects to real-world QA automation skills, from using Git and Python to testing applications with Selenium, JMeter and Postman. This made it easier to understand what I needed to learn and track my progress throughout the internship.
