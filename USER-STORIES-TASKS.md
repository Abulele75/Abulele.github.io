

## ID	Sprint	User Story
### User Stories

| ID | User Story | Sprint |
|---|---|---|
| US01 | As an intern, I want to understand SDLC, STLC and Agile so that I can understand the software development and testing process. | Sprint 1 |
| US02 | As an intern, I want to learn basic Linux commands so that I can perform tasks using the terminal. | Sprint 1 |
| US03 | As an intern, I want to use Git and GitFlow so that I can manage code changes effectively. | Sprint 2 |
| US04 | As an intern, I want to learn Python fundamentals and manage Python environments so that I can develop and maintain test scripts. | Sprint 2 |
| US05 | As an intern, I want to write BDD scenarios using Behave and create a basic Selenium test so that I can automate user interactions. | Sprint 3 |
| US06 | As an intern, I want to use Toolium with Behave so that I can build maintainable UI automation tests. | Sprints 4–5 |
| US07 | As an intern, I want to use JMeter so that I can perform basic performance tests and understand performance metrics. | Sprint 6 |
| US08 | As an intern, I want to use Postman so that I can test APIs, validate responses and perform an end-to-end API testing flow. | Sprint 7 |

## Tasks

Sprint 1 — Testing foundations
1. Set up required accounts and tool access.
2. Study the Software Development Life Cycle (SDLC).
3. Understand the Software Testing Life Cycle (STLC).
4. Learn Agile principles and terminology.
5. Practise basic Linux terminal commands.

Sprint 2 — Git and Python
1. Practise Git commands and version control.
2. Learn the GitFlow branching workflow.
3. Practise Python variables, data types, conditions and loops.
4. Write basic Python functions and scripts.
5. Create and manage Python environments.

Sprint 3 — First automation layer
1. Understand Behaviour-Driven Development (BDD).
2. Write feature files and scenarios using Gherkin syntax.
3. Set up a basic Behave automation project.
4. Create a simple Selenium UI test.
5. Run the test and review its results.

Sprints 4–5 — Framework-based UI automation
1. Set up a Toolium project integrated with Behave.
2. Create and execute framework-based UI tests.
3. Identify stable element locators.
4. Organise test code for maintainability.
5. Run tests and troubleshoot failures.

Sprint 6 — Performance testing
1. Set up Apache JMeter.
2. Create a basic test plan and samplers.
3. Add listeners to view test results.
4. Learn key performance metrics.
5. Run and review a simple performance test.

Sprint 7 — API testing
1. Create a Postman collection.
2. Test common HTTP methods such as GET, POST, PUT and DELETE.
3. Validate response status codes and response data.
4. Organise and execute API requests.
5. Demonstrate an end-to-end API testing flow.

## Reflection
Creating the user stories and tasks helped me break down my internship learning goals into clear, achievable activities. I enjoyed seeing how each task connects to real-world QA automation skills, from using Git and Python to testing applications with Selenium, JMeter and Postman. This made it easier to understand what I needed to learn and track my progress throughout the internship.
