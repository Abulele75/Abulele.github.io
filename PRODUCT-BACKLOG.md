# PRODUCT BACKLOG
**Duration:** 5 months  
**Total Roadmap Sprints:** 7

### Product Goal
Develop practical skills in software testing and automation by completing the seven roadmap sprints, covering testing foundations, source control, UI automation, performance testing and API testing.

| ID | Product Backlog Item | Description | Priority |
|---|---|---|---|
| PB01 | Testing Foundations | Set up access, understand SDLC/STLC and Agile basics, and practise simple Linux terminal tasks. | High |
| PB02 | Source Control and Python | Learn Git/GitFlow, practise Python fundamentals, and manage Python environments using consistent version-control practices. | High |
| PB03 | First Automation Layer | Understand BDD, write Behave-style tests, scaffold an automation project, and create a simple Selenium UI test. | High |
| PB04 | Framework-Based UI Automation | Use Toolium with Behave, identify stable element locators, and build a maintainable UI testing project. | High |
| PB05 | Performance Testing Basics | Set up JMeter, create basic samplers and listeners, understand key performance metrics, and demonstrate a simple performance test. | Medium |
| PB06 | API Testing Flow | Create Postman collections, test common API methods, validate responses, and demonstrate an end-to-end API testing flow. | High |

## Reflection
he product backlog gave me a clear picture of what I would learn during my internship. I was excited to explore tools like Python, Selenium, Behave, Toolium, JMeter and Postman because they were new to me and not covered in my university learning. Gaining hands-on experience with these tools has helped me develop practical skills, understand real-world testing practices and prepare for future employment in the IT industry.
